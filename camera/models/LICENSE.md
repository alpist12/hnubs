# Human models

Source: Innerscene, adapted from MakeHuman CC0 assets. Public domain under CC0 1.0.

- `person-standing.glb`: Daniel, https://www.innerscene.com/tools/library/3d-parts/daniel-3d-person-standing-casual-f788af5a
- `person-seated.glb`: Seated upright (Ellis), https://www.innerscene.com/tools/library/3d-parts/seated-upright-3d-person-seated-c6901f24

Downloaded 2026-11-06 using each source page's Download GLB link. Embedded textures resized to at most 1024×1024; opaque color maps converted to JPEG for browser use; mesh geometry retained. Models are static clothed figures, normalized to the configured height. Seated model height uses its documented 1.36 m seated / 1.74 m standing ratio.
